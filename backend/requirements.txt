# =============================================================================
# SIH 2026 / PS 26139 — backend dependencies
#
# Python 3.11+ REQUIRED. PennyLane 0.45 declares Requires-Python >=3.11 and
# will not install on 3.10. We build against 3.12.
#
# Lives in backend/, alongside the code it describes, mirroring
# frontend/package.json. Run both commands from the REPO ROOT.
#
# INSTALL (two steps, in this order — see backend/README.md):
#
#   pip install torch==2.14.0 torchvision==0.29.0 \
#       --index-url https://download.pytorch.org/whl/cpu
#   pip install -r backend/requirements.txt
#
# Step 1 is not optional on Linux. The default PyPI torch wheel drags in 19
# CUDA packages (nvidia-cublas, nvidia-cudnn, cuda-toolkit, triton, ...) for
# roughly 2.5 GB you will never execute — we run ResNet18 inference and a
# 4-to-10 qubit simulator on CPU. Installing CPU wheels first means the pin
# below is already satisfied and pip skips it. On macOS it makes no
# difference; the command is harmless there.
#
# Every version below was resolved together in one pip pass: 57 packages,
# zero conflicts. Do not bump one in isolation.
#
# After your first successful install on Day 1:
#     pip freeze > backend/requirements.lock.txt   # and commit it
# Four laptops running four different transitive scipy builds is a Day 4 bug
# you cannot afford to debug.
# =============================================================================
